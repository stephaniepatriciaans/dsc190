# DSC190 Project

This repository contains data, parsing scripts, cleaning pipelines, modeling code, and visualizations for analyzing electric vehicle (EV) registrations, population estimates, gasoline prices, and port data across multiple years.

## Repository Structure

```text
dsc190-main/
│
├── Datasets/                 # Raw datasets (CSV/XLSX) including EV registrations, ports data, gas prices, population
│
├── data/
│   ├── processed/            # Cleaned datasets, forecasts, processed images
│   └── raw/                  # Raw data (if present)
│
├── notebooks/                # Jupyter notebooks for analysis and modeling
│
├── reports/                  # Figures generated by analytical workflows
│
├── src/
│   ├── cleaning/             # Data cleaning and preprocessing scripts
│   ├── modeling/             # Forecasting, regression, and analysis models
│   ├── parsing/              # Parsers for raw datasets
│   └── visualization/        # Scripts for plotting and figure generation
│
└── requirements.txt          # Python dependencies
